# Server Policy

NSWAP allows users to add and enable their own syndicated servers. This policy explains how server entries are handled.

## What a server entry is

- A server entry is a URL that NSWAP can use to load content or route the user to a source
- NSWAP stores only the minimal server metadata needed to connect, label, and route that server
- Server entries may be enabled or disabled locally
- NSWAP does not own or control the remote server

## What servers may contain

Approved servers should provide legitimate marketplace or social content and should be reachable and reasonably stable.

## What we will not knowingly support

- Malware or malicious redirects
- Obvious scam infrastructure
- Servers used primarily for illegal content
- Server entries that misrepresent who operates the server

## Operator controls

NSWAP may:

- Disable a server entry that appears unsafe or misleading
- Hide or warn about an entry that is repeatedly reported
- Remove a local server entry from the frontend configuration if needed

## User expectations

- External content may change or disappear without notice
- Different servers may show different data for the same page type
- Users should verify important information before acting on it
- If a page opens on a third-party server, that server’s own rules may apply

## Notes

This policy should stay aligned with the actual onboarding flow, routing logic, and moderation tools in the app.
